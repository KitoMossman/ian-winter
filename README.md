# 9 Jahre Himmel - Roman-Webpräsenz

Dies ist das Repository für die offizielle Website des Romans **"9 Jahre Himmel"** von **Ian Winter**. Die Seite dient als Informationsplattform für Leser und bietet tiefe Einblicke in die Charaktere, die Handlung und die musikalische Untermalung des Buches.

## 📖 Über das Buch

*9 Jahre Himmel* ist eine tiefgründige Erzählung über Seelenverwandtschaft, basierend auf den Tagebüchern des Autors. Sie schildert die außergewöhnliche Verbindung zwischen Ian Wagner und Sarah Winter, die sich allen Konventionen von Alter und Zeit entzieht.

## ✨ Features

- **Modernes Dark-Mode Design**: Ein ästhetisches, premium Design mit der Tailwind-Farbpalette (Slate & Sky) und Fokus auf Lesbarkeit.
- **Interaktive Zeitleiste**: Eine chronologische Reise durch die wichtigsten Meilensteine der Geschichte (1986–1987).
- **Charakter-Deep-Dives**: Detaillierte Profile der Hauptcharaktere Sarah Winter (emotionaler Motor) und Ian Wagner (analytischer Kern).
- **Musik-Integration**: Ein integrierter YouTube-Player für die "Musik im Buch" (Playlist mit ikonischen 80er-Jahre-Songs wie Queen, Dire Straits und Elton John).
- **SEO & Performance**: Vollständige Optimierung durch Meta-Tags, OpenGraph, JSON-LD Schema (Book & Person) sowie eine Sitemap.
- **Datenschutz-Konform**: Ein DSGVO-konformer Cookie-Consent-Banner zur Steuerung externer Ressourcen (Google Fonts, Analytics, YouTube).

## 🛠️ Technologie-Stack

- **Grundgerüst**: Semantisches HTML5.
- **Styling**: [Tailwind CSS v3.4.18](https://tailwindcss.com/) (kompiliert in `style.css`).
- **Logik**: Modernes Vanilla JavaScript (ES6+) für die Zeitleiste, Slideshow und das Cookie-Management.
- **Icons**: SVG-basierte Heroicons.

## 📁 Projektstruktur

- `index.html`: Das Herzstück der Website mit Inhalten, interaktiven Elementen und Schema-Markup.
- `style.css`: Das zentrale Stylesheet des Projekts.
- `img/`: Verzeichnis für Buchcover, Logos und Autorenbild (WebP-optimiert).
- `sitemap.xml` & `robots.txt`: Suchmaschinenoptimierung und Indexierungs-Steuerung.
- `site.webmanifest`: Progressive Web App (PWA) Metadaten.

## 🚀 Lokale Ausführung

Da es sich um eine statische Website handelt, gibt es keine komplexen Abhängigkeiten.

1. Repository klonen.
2. `index.html` direkt im Browser öffnen oder einen einfachen statischen Server verwenden:

    ```bash
    # Beispiel mit Python
    python -m http.server 8000
    ```
